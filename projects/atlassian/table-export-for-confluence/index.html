Confluence Cloud app

Table Export for Confluence

Export the tables on a Confluence page to Excel or CSV. Merged cells remain merged in Excel.

DocumentationInformation for Connect users

Excel and CSV

Export all tables to one Excel workbook or select a table for CSV.

Table structure

Merged cells, line breaks and useful number formats are preserved.

Data handling

The file is created in the browser. TooSolv Studio does not receive page content.

Atlassian Forge

The app uses one permission to read the page currently opened by the user.
