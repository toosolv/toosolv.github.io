Frequently asked questions

What page data can TableFlow access?

It reads only the Confluence page or blog post the signed-in user has open, with that user's existing permissions. It cannot search the site or list other pages.

Where is data stored?

Page content and generated files are never sent to TooSolv Studio. Forge stores only export-history metadata until the user clears it. Interface preferences remain in the browser.

When should I use Excel or CSV?

Choose Excel for merged cells, multiple worksheets, calculated widths and number formatting. Choose CSV for plain data that another tool will import.

Can I export several tables?

Yes. Use one Excel workbook or separate Excel or CSV files in a ZIP. A direct CSV contains one table because CSV cannot contain several worksheets.

Are merged cells preserved?

Yes in Excel. CSV is a plain row-and-column format, so it cannot represent merged cells.

Where does the download go?

Your browser chooses the download folder. TooSolv Studio does not receive or store the file.

What support is available?

Use the support page. A first response is sent within three business days, usually sooner.

How do the free tier, trial and cancellation work?

Sites with up to 10 users pay nothing. Atlassian provides a 30-day trial for paid cloud apps and handles monthly or annual billing. An administrator can cancel through Atlassian. Downloaded files remain on the user's device.
