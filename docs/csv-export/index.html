Export Confluence tables to CSV

Download one table directly or package several tables as separate CSV files in a ZIP.

How to export

  1. Open the page menu, choose Apps, then Export tables (Excel/CSV).
  2. Select CSV. Choose Single for one table or ZIP for several tables.
  3. Choose comma or semicolon, select the required tables and choose Export.

Why several tables require ZIP

A CSV file can contain only one plain table. It has no worksheets and cannot preserve merged cells, colours or column widths. TableFlow therefore creates one CSV file per selected table and groups those files in a ZIP.

Excel compatibility

Files use UTF-8 with a byte order mark. If Excel puts everything into one column, choose the other separator and export again, or import the file through Excel's text and CSV import.
