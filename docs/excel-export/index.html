Export Confluence tables to Excel

Create one workbook with one sheet per table, or download separate Excel files in a ZIP.

How to export

  1. Open the Confluence page that contains the tables.
  2. Open the page menu, choose Apps, then Export tables (Excel/CSV).
  3. Select Excel, choose Single for one workbook or ZIP for separate files, select the tables and choose Export.

What the workbook keeps

  • Merged cells, line breaks and Unicode text
  • Leading zeros and long identifiers as text
  • Locale-aware numbers as real Excel numbers
  • Safe text instead of executable spreadsheet formulas

Sheet names and limits

Sheet names come from nearby headings or expand titles. Invalid Excel characters are replaced, duplicate names receive a number, and names are shortened to Excel's 31-character limit. A page can contain up to 500 tables and 200,000 cells.
