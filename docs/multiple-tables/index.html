Export multiple tables and merged cells

Preview every real table on the page, choose the ones you need and control how the files are delivered.

One workbook or separate files

Excel with Single creates one workbook with one sheet per selected table. Excel or CSV with ZIP creates one file per selected table. CSV with Single is limited to one table because CSV has no worksheet concept.

Merged cells

Row and column spans from normal Confluence tables are reproduced as merged cells in Excel. CSV stores plain rows and columns, so merged layout is intentionally flattened there.

Tables that can be found

Normal tables in page layouts and expand sections are included. Tables rendered by another macro, attachments and images are not part of the page table markup and are not exported.
