Security policy

How we keep the app secure and how to report a vulnerability.

How the app is built

  • The app is built on Atlassian Forge. It has no backend and TooSolv Studio operates no servers.
  • It requests a single read permission (read:page:confluence) and reads pages with the permissions of the signed-in user.
  • Files are created in the browser. Page content stays within Atlassian and your device.
  • The app follows Atlassian's security requirements for Marketplace apps.

Does an export app make it easier to take data out?

It is a fair question, so here is the precise answer. The app asks for exactly one permission, read:page:confluence, and it reads only the page the user has open, as that user, with that user's own permissions. It cannot search, it cannot list or read other pages, it cannot reach a whole space, and it cannot send content anywhere, because we run no server for it to send to. The only thing it reports is a set of plain counters inside Atlassian's own platform, which record that something happened, for example that a page was read or that an export ran, never what was in it (our privacy page lists all of them, and you can switch them off for your site). Everything it can read, the user can already see on screen, select, copy and paste into Excel, or take out with Confluence's own Export to Word and Export to PDF. The app makes that route cleaner, not wider. If your policy is that certain content must not leave Confluence, the controls that work are the ones you already have: page and space permissions, and Atlassian's data security policies, which can block this app in named spaces.

Scope

This policy covers the Table Export for Confluence app, this website (toosolv.github.io) and the address contact@toosolv.com. It does not cover Atlassian's own platform, Confluence Cloud or the Atlassian Marketplace; please report those through Atlassian's own vulnerability programme.

Safe harbour

If you report a vulnerability in good faith, keep to the scope above, do not access, change or delete data that is not yours, and give us reasonable time before making details public, we will not take legal action against you and will treat your report as authorised research.

Report a vulnerability

Please email contact@toosolv.com with the subject "Security report". Include the steps to reproduce and the impact you see. Please do not share details publicly until a fix is released.

What happens next

  • You get an automatic acknowledgement at once, and a personal reply within 3 business days.
  • We fix confirmed vulnerabilities within the timeframes of Atlassian's Security Bug Fix Policy for Marketplace apps.
  • We tell you when the fix is released.
